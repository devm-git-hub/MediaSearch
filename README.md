# 🎬 MediaSearch

A modern and responsive **Media Search Application** built with **React.js** that allows users to search for photo, video or emog using an external API. The application provides a clean user interface with fast search results and detailed media information.

## 🚀 Features

- 🔍 Search movies, TV shows, or media by title
- 📱 Responsive design for desktop, tablet, and mobile
- ⚡ Fast API integration
- 🎨 Clean and modern UI
- 📄 View media details
- ❤️ User-friendly interface
- 🌙 Easy to customize

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3 / Tailwind CSS
- Axios

### API
- TMDB API / OMDb API (depending on your project)

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/MediaSearch.git
```

### Navigate to the project

```bash
cd MediaSearch
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory.

Example:

```env
VITE_API_KEY=YOUR_API_KEY
VITE_BASE_URL=https://api.themoviedb.org/3
```

Replace `YOUR_API_KEY` with your actual API key.
